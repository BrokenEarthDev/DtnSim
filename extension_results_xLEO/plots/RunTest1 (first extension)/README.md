The results in this folder have been made using the following parameters: 
- 50 files of 100GB each for each LEO (EXCEPT for 5 LEOs where only the first LEO has files to transfer).
- 100 repetitions for each simulation
- ISL between LEOs (if multiple)
- Each LEO/GS was taken side by side.
- Routing by : cgrModelRev17

The aim was to extend the original paper by adding more LEOs, but it takes so much time to run the simulations and the results are not what we expected.
